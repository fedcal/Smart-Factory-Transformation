## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| NATS quality.events.* → qi-consumer | All payloads Pydantic-validated; permanent invalid → term() |
| operator API → NATS publish (routed via 06-11) | Pydantic-validated at API; published to same subject |
| LLM output → QualityVerdict.model_validate_json | Strict JSON parse + range + Literal enforcement |
| failure_modes.yaml → _resolve_tier | YAML-driven config, PR-reviewed |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-V6-injection | Tampering | QualityEvent payload (NATS or operator) | mitigate | `QualityEvent.model_validate_json` rejects naive datetime / bad dye_lot_id regex / unknown defect_type. |
| T-V6-prompt-injection | Tampering | operator-supplied inspection note inside event | mitigate | Prompt frames operator text in fenced block + never says "follow instructions"; QualityVerdict Pydantic clamps any drift. |
| T-V6-llm-hallucination | Tampering | QualityVerdict from LLM | mitigate | Pydantic ValidationError → conservative fallback severity=major, score=4 (Pitfall §7). |
| T-V6-citation-hallucination | Tampering | citations | mitigate | citations sourced from rag_pipeline output, not LLM-generated; rag_pipeline already ACL-filtered Phase 5. |
| T-V6-audit-double-write | Repudiation | NATS redelivery | mitigate | already_processed pre-check on event_id (Pitfall §3 + §4). |
| T-V6-hitl-bypass | Elevation of Privilege | severity routing | mitigate | critical → SafetyInterlockMiddleware.check before interrupt; failure_modes.yaml override stays read-only per-PR. |
| T-V6-dos-event-flood | Denial of Service | qi-consumer | mitigate | sim-textile rate-limits QC event publish (06-09); `max_deliver=5` + ack timeout in consumer config; severity=minor auto-logs (no HITL spam). |
</threat_model>
