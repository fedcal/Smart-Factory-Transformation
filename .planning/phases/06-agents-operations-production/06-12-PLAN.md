<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HTTP client → /v1/quality/events | Pydantic-validated payload + Idempotency-Key |
| HTTP client → /v1/agents/* | Pydantic-validated; user_roles propagated to supervisor state |
| router → supervisor_graph | Internal call; supervisor wires further to ops cluster (06-05 routing) |
| router → NATS | Publishes to quality.events.* with server-forced source=operator |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-V6-injection | Tampering | endpoint payloads | mitigate | Pydantic frozen+extra=forbid on QualityEventOperatorRequest, AnomalyScanRequest, PlanRequest, OperatorChatRequest; 422 on bad payloads. |
| T-V6-source-spoof | Spoofing | QualityEvent.source field | mitigate | Server forces `source="operator"` on the /v1/quality/events route; client cannot inject simulator-source events. |
| T-V6-acl-leak | Information Disclosure | user_roles in body | mitigate (Phase 6 dev-mode) | Phase 11 will replace with JWT-derived claims; doc this as known limitation in assumptions/register.yaml. |
| T-V6-idempotency-replay | Tampering | duplicate submissions | mitigate | Idempotency-Key middleware caches response by Key + body-hash (approvals pattern). |
| T-V6-recursion-bomb | Denial of Service | supervisor graph recursion | mitigate | config["recursion_limit"]=5 enforced; safe_invoke escalates overflow to HITL. |
</threat_model>
