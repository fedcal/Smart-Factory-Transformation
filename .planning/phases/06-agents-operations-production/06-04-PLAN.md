## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-V6-yaml-injection | Tampering | YAML loaders | mitigate | `yaml.safe_load` only (Phase 1+ T-V5-yaml convention); never `yaml.load`. |
| T-V6-injection-dye-lot | Tampering | QualityEvent.dye_lot_id | mitigate | Annotated Field with regex `^DL-[A-Z0-9-]+-\d{8}-[0-9a-f]+$`; rejects any operator-supplied value that doesn't match (D-QI-04). |

| T-V6-baseline | Tampering | anomaly_baselines.yaml | mitigate | YAML file in repo, PR-reviewed; Pydantic schema validation on load; CI validator asserts cross-ref to registry. |
| T-V6-naive-datetime | Tampering | All Pydantic datetime fields | mitigate | tz-aware field_validator on every datetime field (Pitfall 7). |
| T-V6-yaml-drift | Repudiation | orders.yaml ↔ asset_capacity.yaml ↔ registry.yaml | mitigate | CI test_yaml_validators.py asserts cross-refs at every PR. |
