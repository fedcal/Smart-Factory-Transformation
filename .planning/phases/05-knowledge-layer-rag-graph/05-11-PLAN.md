<objective>
Close VERIFICATION.md gap 1 (KNW-09 BLOCKER / CR-01): TraverseGraphTool._arun()
accepts arbitrary strings for seed_label and relation_path because Pydantic
Literal validation only fires on the args_schema/ainvoke() path. Direct _arun()
calls bypass the whitelist and compose destructive Cypher. The verifier reproduced
the bypass in-process with payload `seed_label='Machine) DETACH DELETE n MATCH (x'`.

Purpose: prevent Cypher injection from reaching Neo4j when an agent or test
calls `_arun` directly. Defense-in-depth: re-validate inputs inside `_arun` via
`TraverseGraphInput(**kwargs)` so the Pydantic whitelist is the single source of
truth regardless of entry point. Without this fix, Phase 6 agents (which wire
TraverseGraphTool into LangChain runnables) inherit a fail-open attack surface.

Output: hardened `_arun` body that constructs a validated `TraverseGraphInput`
before composing Cypher; a regression test that calls `_arun` directly with the
verifier payload and asserts ValidationError; corrected `_run` docstring.
</objective>
